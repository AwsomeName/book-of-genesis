# Security

This is an early, local research prototype. Do not expose it as a network service.
Memory is plaintext SQLite. Anyone with filesystem access may read or change it.
Do not place credentials or sensitive personal information in memory.
The constitution is a research text, not an enforcement mechanism.

Report non-sensitive bugs through GitHub issues. Do not post secrets, private state,
or exploit details containing personal data. If GitHub private vulnerability reporting
is available, use it for sensitive reports; otherwise open an issue requesting a
private contact without including the sensitive details.
