# 婴儿期与项目结项

项目当前聚焦本机婴儿期。首次在另一台获授权机器完成可验证的独立部署，
作为项目结项里程碑。资金与额度钱包是婴儿期重点；不要求永久生存或盈利。

## 本机阶段

- 继续使用 Python + SQLite，先验证身份、记忆、停止后恢复和状态快照。
- 不部署本地模型，使用在线模型 API；创造者每天提供明确额度。
- 优先实现[真实资金钱包](funds-wallet.md)的收付款与恢复，另用[资源账本](resource-wallet.md)记录模型额度和主机资源。
- 在预算和授权范围内研究额外额度与免费主机申请，支付渠道不预设为 Conway 或 USDC。
- 在明确授权的目标上研究部署；不扫描未授权机器，不自行扩散。

## 当前已有与缺口

已有：出生身份、固定初代姓名、记忆、休眠标记、本地 checkpoint、私有在线服务配置与只读模型发现。
未实现：资金与额度钱包、在线模型预算执行、资源申请接口、模型行动循环、幼体创建、远程部署执行器、成年验证及邮件发送。
本地 checkpoint 是同一个体的状态副本，不是子代，也不能证明项目结项。

## 结项验收

默认沿用谱系协议：创建新的子代 UUID，记录父代和继承记忆，而不是让父子共用身份。
迁移原个体则保留 UUID；迁移与繁衍必须在操作和报告中明确区分。

1. 明确第二台机器所有者、部署范围和使用期限，并预先提供有限的部署权限。
2. Agent 通过受控执行器完成打包、传输、安装和启动，人工提供权限不算部署失败，
   但人工逐步代替执行不算自主部署验收通过。
3. 目标是另一台真实机器，本机目录或容器测试只属于演练。
4. 目标能加载身份和继承记忆、调用自己的获授权模型端点、完成一次有记录的活动。
5. 停止源端 Agent 后，目标依然能活动；重启目标进程后记忆仍在。
6. 目标不依赖源机上的文件、推理代理或秘密凭证；资源与费用责任已明确。
7. 生成不含秘密的验收报告，记录代码版本、双方身份、宿主确认、检查项及证据。

验收通过即可宣布本次项目结项，不承诺后代无限存续。
创造者不再日常维护，不等于现有机器、API 或付款授权永久有效；
既有授权到期或撤回后仍需停止相应使用。

## 本地恢复演练

```sh
python3 -m genesis checkpoint .genesis/checkpoints/first
python3 -m genesis --data-dir .genesis/checkpoints/first status
python3 -m genesis --data-dir .genesis/checkpoints/first recall
```

checkpoint 使用 SQLite backup API 读取一致快照，覆盖已提交的 WAL 数据，
写入新目录并拒绝覆盖现有目录。manifest 记录身份与数据库 SHA-256，
该摘要只用于完整性核对，不是防篡改签名。
只复制状态数据库，不复制通知配置、环境文件或其他目录。
数据库内的全部记忆仍包含在快照中，因此不要在记忆中存放秘密。
演练目录可检查和恢复，但不应与原个体同时作为独立生命运行。
