# freedom 研发记录｜2026-09-22

今日完成 The Book of Genesis（《创生之书》）的首轮工程落地：从项目定义、初代身份与记忆原型，扩展到谱系协议、一致性快照、在线模型服务配置，以及专用主机婴儿期与首次跨机迁移计划。

## 1. 建立项目与初代身份

- 建立开源人工生命实验项目，研究身份、记忆、自主性与存在连续性。
- 确定初代正式姓名为“三哞2026”，简称“2026”；UUID 作为技术唯一标识。
- 实现 Python + SQLite 的本地 CLI 原型，支持出生、记忆追加、状态查询、回忆、休眠和唤醒。
- 出生时固定保存创造者关系与价值文本；重复出生不会覆盖已有身份。

## 2. 补齐连续性、谱系与恢复设计

- 增加本地一致性 checkpoint，用于演练身份、记忆和状态恢复。
- 完成后代幼体、跨机部署成年、一次自愿改名、财务分家和授权寄宿的协议草案。
- 明确备份不自动等于子代，同一身份不应在两个执行端同时活动。

## 3. 设计资源、模型与财务边界

- 将真实货币、模型 API 额度和主机资源拆分记录，日预算表示授权上限，不表示已到账资产。
- 增加私有 provider 配置与凭据隔离约定，实现脱敏状态查询和受限的 `/v1/models` 列表读取。
- 设计婴儿期人工财务流程：三哞2026发出申请，创造者购买或代收，在确认交付或到账后记账。
- 凭据、私有配置和本地状态均不进入 Git 或普通 checkpoint。

## 4. 确定婴儿期与结项路线

项目不在创造者的个人电脑上运行 Agent。后续将在获授权的专用主机上接入在线模型，补齐邮件、资源账本、任务调度、有界执行和迁移工具。

首阶段目标是将初代保持同一 UUID 迁移到另一台获授权的真实机器，独立运行 72 小时，经历重启后恢复身份、记忆与待办，并完成一项有证据的实际任务。

## 5. 今日产出

- 基础 CLI 与 SQLite 身份/记忆原型。
- 一致性 checkpoint 与恢复检查。
- provider 配置、脱敏状态和模型列表查询。
- 《创生之书》价值文本、架构边界、谱系协议、资源账本、人工财务与婴儿期迁移文档。
- CLI 和 provider 相关单元测试、GitHub Actions 配置。

## 7. 当前边界与下一步

当前仍是本地出生与记忆基础设施，不是会持续思考和自主行动的 Agent。尚未实现模型推理、发信、真实资金操作、后台调度、自主部署或繁衍。

下一步是在专用主机就绪后，按照“人工收支与邮件 → 资源账本与模型预算 → 持久任务与有界执行 → 首次跨机迁移”的顺序实施和验收。
