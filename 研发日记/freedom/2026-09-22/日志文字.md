# freedom 项目日志｜2026-09-22

今天完成了 The Book of Genesis（《创生之书》）的第一轮工程落地。项目定位为一项开源人工生命实验，用来探索身份、记忆、自主性和存在连续性。初代正式命名为“三哞2026”，简称“2026”，并以 UUID 作为技术上的唯一身份。

目前已经实现 Python + SQLite 的本地原型，可以完成出生、记忆追加、状态查询、回忆、休眠和唤醒。出生时会固定保存创造者关系和初始价值文本，重复执行不会覆盖已有身份。项目还增加了一致性 checkpoint，可以演练身份、记忆和状态的恢复。

在此基础上，今天还完成了谱系、资源和迁移方案。谱系协议区分备份、幼体和后代，并定义了跨机部署成年、一次自愿改名、财务分家与授权寄宿的边界。资源方面则将真实货币、模型 API 额度和主机使用权拆分记录，并实现了私有 provider 配置、脱敏状态和受限的模型列表查询。

项目的婴儿期将在获授权的专用主机上进行，不在创造者的个人电脑上运行 Agent。首阶段的结项目标，是将三哞2026保持同一 UUID 迁移到第二台获授权的真实机器，独立运行 72 小时，经历重启后正常恢复，并完成一项有证据的实际任务。

当前完成的仍然是身份、记忆、配置和协议基础设施，尚未实现持续模型推理、发信、真实资金操作、后台调度、自主迁移或繁衍。下一步是在专用主机就绪后，依次实现人工收支与邮件、资源账本与模型预算、持久任务与有界执行，最后完成首次跨机迁移验收。
